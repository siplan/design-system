# Lucida Sans Unicode — nota de licenciamento

Fonte proprietária de Bigelow & Holmes Inc., distribuída pela Microsoft/Monotype junto ao
Windows e ao pacote Office. **Não é uma fonte de distribuição livre** (ao contrário do Roboto).

- Arquivo de origem: `LucidaSansUnicode.ttf`, fornecido pelo usuário a partir de uma instalação
  Windows licenciada (`l_10646.ttf`).
- `LucidaSansUnicode.woff2`: conversão do `.ttf` original para uso web (mesmo conteúdo,
  formato comprimido), gerada via `fonttools`.
- Uso restrito a este design system interno da Planejar (consumo pelas aplicações da própria
  organização). Não redistribuir o arquivo de fonte fora deste contexto nem publicar o pacote
  em registro público (npm público, CDN aberto) sem confirmar os termos de licença da Monotype.
